# Kenace’s WorldEase Feedback

Bug reports and feature requests for **Kenace’s WorldEase**, a Minecraft Java accessibility and comfort mod.

Use this repository to report a problem or suggest an improvement. Please check existing issues first so related feedback stays together.

## Reporting a bug

Open a new issue and include as much of the following as you can:

- A short, specific title.
- What you were doing when the problem happened.
- Steps to reproduce it.
- What you expected to happen and what happened instead.
- Your Minecraft version, WorldEase version, Fabric Loader version, and Fabric API version.
- Other installed mods that might be relevant.
- A crash report or relevant log excerpt, if available.

If the problem is intermittent, mention how often it happens. Remove account names, server addresses, or other private information before posting logs.

## Suggesting a feature

Open an issue describing:

- The accessibility or comfort problem you want to solve.
- When or how it affects your play.
- The change you have in mind, if you have one.

Suggestions are welcome even if you are unsure how they could be implemented.

## Be considerate

Please keep reports constructive and focused. One issue per report makes feedback easier to follow. Add information to an existing issue when it describes the same problem or idea.
